# Jogo da Velha — UNIFOR

Aplicação web do Jogo da Velha desenvolvida como atividade de Engenharia de Software Orientada a Requisitos (Spec-Driven Development), tendo como referência o Caso de Uso (CDU) **Jogar Jogo da Velha** fornecido pela UNIFOR.

## Funcionalidades

A aplicação contempla os comportamentos especificados no CDU, incluindo:

- modo **2 Jogadores (PVP)**;
- modo **Contra o Computador**;
- formato **Partida Única**;
- formato **Melhor de 3 (MD3)**;
- placar de vitórias;
- contador de rodada;
- detecção de vitória e empate;
- destaque visual da linha vencedora;
- confetes na vitória;
- efeitos sonoros sintetizados por Web Audio API;
- botão para reiniciar a partida;
- interface seguindo a identidade visual indicada no CDU.

## Execução local

Como a aplicação está contida em um único arquivo HTML, ela pode ser executada diretamente em um navegador compatível com JavaScript e Web Audio API.

1. Acesse a pasta `src`.
2. Abra o arquivo `index.html` em um navegador.
3. Utilize os seletores de modo e formato para testar as diferentes funcionalidades.
